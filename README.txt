# Week 1 – Analyze Student Marks Dataset

## Files
- `Week1_Student_Marks_Analysis.ipynb` — complete assignment notebook with explanations and code.
- `StudentsPerformance.csv` — original dataset provided for the assignment.

## How to run
1. Open Google Colab: https://colab.research.google.com/
2. Upload `Week1_Student_Marks_Analysis.ipynb`.
3. Upload `StudentsPerformance.csv` into the Colab session (left sidebar → Files → Upload).
4. Run all cells from top to bottom.
5. To submit, share the Colab notebook link if your instructor accepts links, or download the notebook / export it as PDF if a file upload is required.

The notebook checks missing data, cleans values if needed, calculates average/minimum/maximum marks, and displays Pandas summaries.
